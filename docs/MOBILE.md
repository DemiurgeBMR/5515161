# Мобильная версия сайта (режим «приложение»)

На экранах **до 768px** (телефоны, планшет в портрете) сайт работает как мобильное приложение:
компактная шапка, нижняя панель вкладок по ролям, шторки вместо выпадающих меню и модальных окон,
таблицы превращены в карточки. **Выше 768px (десктоп, планшет лёжа) ничего не меняется** — все
телефонные правила лежат внутри `@media (max-width: 768px)`, а мобильные блоки разметки по умолчанию скрыты.

## Из чего состоит

| Что | Где |
|---|---|
| Нижняя панель вкладок и шторка «Профиль/Ещё» (разметка, состав вкладок по ролям) | `public_html/includes/mobile_nav.php` (подключается из `includes/footer.php`) |
| Компактная шапка, панель, шторки, модалки-шторки, тосты, безопасные зоны | `public_html/assets/css/layout/_mobile-shell.css` |
| Общие «кирпичики» (карточки, чипы, строки списков, кнопки, липкая кнопка, таблица→карточки, формы) | `public_html/assets/css/components/_m-ui.css` |
| Телефонные правила страниц — по одному файлу на страницу или группу | `public_html/assets/css/pages/m/_m-*.css` (подключены в `assets/css/style.css`) |
| Движок шторок, бейджи панели, определение экранной клавиатуры | `public_html/assets/js/rr-mobile.js` |
| Поведение конкретных страниц на телефоне | `public_html/assets/js/m/*.js` |
| Иконки (в т.ч. для мобильных экранов) | `public_html/includes/icons.php` (`rr_icon('имя')`) |

Подключение — только через `style.css` и `footer.php`; отдельных шагов сборки нет.

## Как это устроено

- **Вкладки панели** по ролям (гость, оператор, собственник, админ) и пункты шторки меню — один массив в
  `rr_mobile_nav_config()` (`includes/mobile_nav.php`). Подсветка вкладки — по пути страницы (`match`), страницы,
  которых нет в панели, подсвечивают «Профиль/Ещё». Бейдж «Заявки» — число непрочитанных сообщений
  (сервер при загрузке, потом `unread_messages` из `api/get_notifications.php`).
- **Хелперы видимости:** `.m-only` — только на телефоне, `.m-hide` — только на десктопе. Так одна и та же разметка
  показывает разные блоки; блок для телефона нельзя дублировать с теми же `id`/`name`.
- **Классы на `<body>`:** `m-no-tabbar` — убрать нижнюю панель (чат, карточка локации, формы); `m-has-cta` — на
  странице есть липкая кнопка `.m-sticky-cta`, под неё резервируется место.
- **Шторка** — любой `.m-sheet` с `id`: открывается `[data-m-sheet-open="id"]` или `RRMobile.openSheet(id)`,
  закрывается `[data-m-sheet-close]`, фоном, Esc, свайпом вниз и кнопкой «Назад» телефона. Выше 768px `.m-sheet` —
  обычный блок без стилей, поэтому фильтры/формы остаются на странице, а на телефоне выезжают снизу.
  События: `m-sheet:open`, `m-sheet:close`. Переход по ссылке из шторки сначала закрывает её (история остаётся чистой).
- **Таблица → карточки:** `<table class="m-table-cards">`, у каждой `<td>` — `data-label="Название колонки"`.
- **Поля ввода** на телефоне — 16px (иначе iOS приближает страницу при фокусе), зоны нажатия — не меньше 44px
  (чипы — 36–40px). Высоту видимой области с учётом клавиатуры отдают переменные `--m-vvh` / `--m-vvt`; для
  полноэкранных блоков вместо `100vh` берите `100dvh`.
- **Тёмная/светлая тема** — только через переменные темы (`var(--bg-elevated)`, `--accent`, …).

## Обучение (rr-tour.js) на телефоне

Шаг может содержать поля `only: 'phone'|'desktop'`, `phone: {…}` (поля, заменяющие основные на телефоне) и
`dock: 'top'|'bottom'|'auto'` (к какому краю прижать карточку, если цель закреплена у низа экрана — панель, шторка).
На телефоне «Меню аккаунта» — это шторка «Профиль», боковое меню кабинета заменено шагом про нижнюю панель.
Меняя вёрстку страниц, проверяйте селекторы обучения: `grep "target:" public_html/assets/js/rr-tour.js`.

## Чек-лист при добавлении или правке страницы

1. Телефонные правила — только в `pages/m/_m-<страница>.css` внутри `@media (max-width: 768px)`.
2. Нет горизонтальной прокрутки на 320px; нет обрезанного текста; кнопки ≥ 44px; поля 16px; текст ≥ 12px.
3. Широкое содержимое: таблицы → карточки (`m-table-cards`) или внутри контейнера с `overflow-x: auto`.
4. Проверить в тёмной и светлой теме, в портрете (320–430px) и альбомной (667×375) ориентации.
5. Десктоп (≥ 1025px) не изменился.
6. Страница с полем ввода/липкой кнопкой — `body.m-no-tabbar` (+ `m-has-cta`).

## Известные ограничения

- Экранная клавиатура проверялась имитацией (`visualViewport`), на реальных iOS/Android — нет; рекомендуется
  пройтись по чату, формам и фильтрам на живых устройствах.
- PWA (установка на экран «Домой», иконки, `manifest.json`) не делалась.
- Телефон собственника/оператора на сайте по политике конфиденциальности не показывается, поэтому в карточках
  вместо «Позвонить» — кнопки «Написать» (чат).
