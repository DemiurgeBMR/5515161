# Сайт гостиницы рядом с онкодиспансером (Симферополь)

Одностраничный сайт с заявкой на бронирование, правилами проживания и
документами по персональным данным. PHP без фреймворков и сборки: работает на
любом обычном хостинге с PHP 8.1+ и расширением `mbstring`.

Сайт самостоятельный и никак не связан с остальным кодом репозитория.

## Запустить у себя

```bash
php -S localhost:8080 -t hotel/public
```

и открыть http://localhost:8080.

## Как устроен сайт и почему так

Макет взят за основу: палитра, шрифты, арка на первом экране, тёмный блок бани.
Доработано то, что важно именно этим гостям.

**Кто гости.** Люди, приехавшие из других городов Крыма на обследование,
химио- или лучевую терапию (курс — несколько недель), и их близкие, которые
навещают пациента в стационаре. Многие — старшего возраста, устают, приезжают
ночными поездами и автобусами, сроки лечения у них часто сдвигаются.

**Что из этого следует:**

| Решение | Почему |
|---|---|
| Крупный шрифт (17–18 px), высокий контраст, большие кнопки | Макет набран мелким светло-серым текстом — пожилому человеку с телефона это не прочитать |
| Телефон виден всегда: в шапке, в меню, в нижней панели на телефоне, рядом с формой | Многие гости проще позвонят, чем заполнят форму |
| Блок «Во время лечения» | Ранний заезд после ночной дороги, перенос брони при сдвиге сроков, холодильник для лекарств, жильё вместе с близким, документы для работодателя — это и есть главные вопросы гостей |
| Форма считает стоимость сразу, со скидкой за длительное проживание | «Честные условия» из макета: гость видит итог до звонка |
| Быстрая форма на первом экране — только даты, номер и число гостей | В макете там был ещё и телефон. Просить телефон до того, как человек увидел цену, — лишнее препятствие; к тому же поле телефона требует согласия на обработку данных |
| Выбор «позвонить / написать в мессенджер» | Пациент на процедурах не может ответить на звонок |
| Подсказка «не пишите диагноз в комментарии» | Сведения о здоровье — особая категория персональных данных, для брони они не нужны |
| Отдельная страница согласия на обработку данных | С 1 сентября 2025 года согласие должно быть отдельным документом, а не пунктом политики |
| Нет отзывов на сайте — ссылки на Яндекс Карты и 2ГИС | Отзывы на собственном сайте не вызывают доверия; там же гостиницу и ищут |
| Аэропорт не указан в «Что рядом» | Аэропорт Симферополя с 2022 года не принимает рейсы, гости едут поездом, автобусом или на машине. Если это изменится — добавьте его в `nearby` в конфиге |
| Под баней — «посоветуйтесь с лечащим врачом» | Во время лечения баня противопоказана многим, и гости это оценят |
| Шрифты на своём сервере, Яндекс Карта грузится по кнопке | Быстрее на слабом мобильном интернете и ничего не уходит третьим сторонам без спроса |
| Всё работает без JavaScript | Формы отправляются как обычные HTML-формы, меню и карта просто становятся статичными |

## Где что менять

**Все данные гостиницы — в одном файле `config/hotel.php`:** название, телефон,
адрес, мессенджеры, цены, скидки, состав номеров, реквизиты. Цена, изменённая
там, меняется везде: в карточках, таблице цен, форме, расчёте, письме
администратору и разметке для поисковиков.

Значения в `[квадратных скобках]` — заглушки. Проверить, что ничего не забыто:

```bash
php hotel/tools/check.php
```

Скрипт перечислит все незаполненные места — в конфиге и в текстах страниц
(правила, политика, вопросы).

**Куда приходят заявки** — `config/secrets.php` (создать из
`config/secrets.example.php`, в git не попадает). Рекомендуется почта на
российском сервисе. Telegram-уведомления возможны, но это трансграничная
передача персональных данных — подробности в комментариях файла.

Если ни один канал не настроен или отправка не удалась, сайт не делает вид,
что всё хорошо: гость видит кнопки «Позвонить» и «Отправить в WhatsApp» с уже
готовым текстом заявки.

**Фотографии номеров.** Положите файлы в `public/assets/img/rooms/` и укажите
их в `photos` у номера в конфиге — в карточке появится листаемая галерея.
Рекомендации: 1600 px по длинной стороне, JPEG или WebP до 300 КБ, дневной
свет. Гостям важнее всего увидеть кровать, санузел, холодильник и кухню, а
также вход в здание — чтобы узнать его, когда приедут. Фото для первого экрана
и бани — замените `photo_placeholder(...)` в `public/index.php` на `<img>`.

## Перед запуском

- [ ] `php hotel/tools/check.php` ничего не находит.
- [ ] Каждое утверждение на сайте — правда. Особенно проверьте: ранний заезд и
      хранение багажа, перенос брони, холодильник в каждом номере, кухня,
      справка о проживании, «скидка на весь срок», вместимость номеров.
      Чего нет — уберите, а не оставляйте «на будущее».
- [ ] Номер в реестре средств размещения указан в конфиге.
- [ ] Подано уведомление в Роскомнадзор об обработке персональных данных
      (pd.rkn.gov.ru) — сайт собирает имена и телефоны.
- [ ] Правила проживания, политика и согласие просмотрены юристом и в них
      проставлены даты редакций.
- [ ] Заявка с сайта доходит до администратора (отправьте тестовую).
- [ ] Корень сайта на хостинге — папка `hotel/public`; папки `config`, `src`,
      `storage` лежат уровнем выше и снаружи недоступны. Папка `storage`
      доступна PHP на запись (нужна для защиты формы от спама).
- [ ] Включён HTTPS.
- [ ] В `public/robots.txt` и `site_url` в конфиге — настоящий домен.
- [ ] Гостиница добавлена в Яндекс Бизнес (карточка на Картах) и 2ГИС, ссылки
      на карточки — в конфиге. Большинство гостей найдут гостиницу именно там,
      по запросу «гостиница рядом с онкодиспансером».
- [ ] Сайт добавлен в Яндекс Вебмастер, отправлена карта сайта
      (`/sitemap.xml`).

## Структура

```
hotel/
├── config/
│   ├── hotel.php            — все данные гостиницы
│   └── secrets.example.php  — шаблон настроек отправки заявок
├── src/
│   ├── bootstrap.php        — хелперы, расчёт стоимости
│   └── partials/            — шапка, подвал, иконки
├── public/                  — корень сайта
│   ├── index.php            — главная
│   ├── rules.php            — правила проживания
│   ├── privacy.php          — политика обработки персональных данных
│   ├── consent.php          — согласие на обработку персональных данных
│   ├── api/booking.php      — приём заявок
│   ├── sitemap.php          — карта сайта (/sitemap.xml)
│   └── assets/              — стили, скрипт, шрифты
├── storage/                 — временные файлы защиты от спама
└── tools/check.php          — проверка готовности к запуску
```

Шрифты Cormorant Garamond и Manrope — SIL Open Font License (лицензии лежат
рядом с файлами шрифтов). Иконки — Lucide, лицензия ISC.

## Что можно добавить потом
