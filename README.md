# Сайт гостиницы в Симферополе (ул. Генерала Родионова, 7А)

Сайт с бронированием прямо в базу и простая CRM для администратора.
PHP 8.1+ и MySQL/MariaDB, без фреймворков, сборки и Composer — работает на
обычном хостинге и в Open Server.

**Для гостей**

- календарь свободных дат по каждому номеру — обновляется сам, пока страница
  открыта; заезд с 13:00, выезд до 12:00;
- заявка с расчётом стоимости сразу: сезонные цены, скидка за длительное
  проживание, предоплата; занятые даты забронировать нельзя;
- письмо с номером брони и личной ссылкой: на странице брони видно статус,
  оплату и можно попросить продлить, перенести или отменить;
- «Мои брони» — вход по коду из письма, без паролей;
- баня и хамам (`/bath.php`): фото, цены, правила и запись на свободное
  время — когда владелец её откроет.

**Для администратора — `/admin/`**

| Раздел | Что там |
|---|---|
| Сегодня | заезды и выезды, новые заявки, сообщения гостей, брони без нужного статуса, двойные продажи |
| Шахматка | все комнаты по датам; бронь заводится нажатием на пустую клетку, комнату можно закрыть на ремонт |
| Уборка | какие номера пора убрать; отметка «Убрано», разовые уборки, как часто убирать у проживающих |
| Брони | поиск по имени, телефону, почте и номеру; карточка: статусы, оплаты и возвраты (со сдачей), письма гостю, история |
| Баня | расписание по дням, заявки с сайта, запись по телефону, закрыть время; оплаты; статус (открывает владелец), описание, фото, цены и часы работы; кто ждёт открытия |
| Гости | карточки гостей, кто ждёт открытия бани, срок хранения данных |
| Номера и фото | типы номеров (что видит гость), настоящие комнаты, фото номеров и главной |
| Цены | цена за ночь, сезонные цены и праздники, скидки за срок, предоплата, калькулятор |
| Отчёты | загрузка, выручка, оплаты по месяцам; выгрузка броней и платежей в Excel |
| Площадки | обмен занятостью с Авито, Суточно.ру и др. через календари iCal |
| Сотрудники | владелец добавляет администраторов и горничных, выдаёт временные пароли |
| Журнал | кто, когда и что менял |

**Для горничной — тоже `/admin/`, но видит она только «Уборку»:** какие
номера убрать и к какому времени, есть ли сегодня заезд в номер. Имён и
телефонов гостей, броней и денег у горничной нет — даже по прямой ссылке.

Уведомления — только по почте: администраторам о новой заявке и сообщениях
гостей, горничным — когда пора убрать номер, гостю — о получении заявки, подтверждении, отмене, напоминание
накануне заезда и коды входа. Админка удобна с телефона: меню выезжает сбоку,
таблицы превращаются в карточки, шахматка листается вбок.

## Запустить у себя в Open Server Panel 6

1. Поставьте Git для Windows (https://git-scm.com/download/win) и в Git Bash
   скачайте проект в папку проектов OSP:

       cd /c/OSPanel/home
       git clone -b claude/serene-franklin-e3wors https://github.com/DemiurgeBMR/5515161.git hotel

   Если папка уже есть — обновите её: `cd /c/OSPanel/home/hotel && git pull`.
2. Проверьте, что в `C:\OSPanel\modules` есть `Apache`, `PHP-8.5` и
   `MySQL-8.0`. Если версия PHP другая (от 8.1), поменяйте `php_engine` в
   `.osp/project.ini` — иначе OSP молча не покажет сайт.
3. В консоли OSP включите базу и создайте таблицы:

       osp on MySQL-8.0
       osp project hotel
       cd /d C:\OSPanel\home\hotel
       php tools\migrate.php

   Скрипт сам создаст базу `hotel` и заполнит номера, цены и скидки из
   макета. Запускайте его после каждого `git pull` — это безопасно.
4. Полностью перезапустите Open Server и откройте **http://hotel/** — сайт,
   **http://hotel/admin/** — админка. При первом входе админка предложит
   создать владельца: имя, почта и пароль.
5. Письма по умолчанию не отправляются, а складываются в `storage/mail.log` —
   так удобно проверять. Как включить настоящую отправку — ниже.

Если `osp project hotel` пишет «Нет конфигурации среды», OSP ещё не увидел
проект — перезапустите его. Без Open Server: `php -S localhost:8080 -t public`
и база в `config/secrets.php`.

## Настройки: `config/secrets.php`

Скопируйте `config/secrets.example.php` в `config/secrets.php` (в git он не
попадает — там пароли). Без файла сайт работает с настройками Open Server:
база на `MySQL-8.0`, пользователь `root` без пароля, письма — в лог.

- **База:** `db_host`, `db_name`, `db_user`, `db_pass` — на хостинге берутся
  из панели хостинга.
- **Почта:** `mail_transport` = `smtp`, ящик на Яндексе: `smtp_user` — адрес,
  `smtp_pass` — пароль приложения (Яндекс ID → Безопасность → Пароли
  приложений → Почта), `mail_from` — тот же адрес. Письма о заявках получают
  сотрудники, у которых в профиле включены письма, и адреса из `notify_extra`.
- **`setup_key`** — нужен один раз на хостинге, чтобы создать владельца:
  `/admin/login.php?setup=ключ`. С вашего компьютера владелец создаётся и без
  ключа.

## Перенести на хостинг

Нужны PHP 8.1+ с расширениями `pdo_mysql`, `mbstring`, `gd`, `curl` (и
желательно `exif`), MySQL 8 или MariaDB 10.4+ и доступ по SSH — он есть на
Beget, Timeweb, REG.RU и других.

1. Загрузите проект; корнем сайта сделайте папку `public` — папки `config`,
   `src`, `storage`, `tools` должны лежать уровнем выше и снаружи быть
   недоступны. Если хостинг не даёт сменить корень, сработает запасной
   `.htaccess` в корне проекта: он отправит запросы в `public/` и закроет
   служебные папки (нужен Apache — он есть почти на всех хостингах).
2. Создайте базу в панели хостинга, заполните `config/secrets.php`, по SSH
   выполните `php tools/migrate.php`.
3. Создайте владельца: откройте `/admin/login.php?setup=ваш_setup_key` или по
   SSH `php tools/admin.php add почта "Имя" owner` (выдаст временный пароль).
4. В планировщике (cron) хостинга добавьте раз в 15 минут
   `php /путь/к/сайту/tools/cron.php` — напоминания гостям, обновление
   календарей площадок, удаление устаревших данных. Без планировщика это тоже
   работает, но только пока кто-то открывает админку.
5. Папки `storage` и `public/uploads` должны быть доступны PHP на запись.
6. Включите HTTPS и ежедневные резервные копии базы и папки `public/uploads`
   в панели хостинга.
7. `php tools/check.php` — покажет всё, что ещё не заполнено.

## Как устроено бронирование

- **Ночи.** Бронь занимает ночи с даты заезда до даты выезда: если один гость
  выезжает 10-го в 12:00, другой может заехать 10-го в 13:00.
- **Тип номера и комната.** Гость выбирает тип (Стандарт, Люкс…), бронь
  занимает конкретную комнату. Сколько комнат типа — столько броней на одни
  даты. Комнаты добавляются в «Номера и фото».
- **Статусы:** Заявка → Подтверждена → Проживает → Выехал, а также Отменена и
  Не приехал. Заявка уже держит комнату — подтвердите или отмените её быстро.
- **Двойных броней не бывает:** при сохранении комнаты блокируются в базе,
  две одновременные заявки на последний номер не пройдут обе.
- **Цены.** Цена ночи — базовая цена номера или сезонное правило (своя цена
  номера или процент для всех). Скидка за длительное проживание — на весь
  срок. Предоплата считается по правилу из «Цены», оплату принимаете сами
  (перевод, наличные) и отмечаете в брони. Уже заведённые брони при смене цен
  не пересчитываются.
- **Площадки.** У каждой комнаты есть ссылка-календарь для Авито, Суточно.ру
  и др.; их календари вставляются в «Площадки» и закрывают даты на сайте.
  Обновление — раз в 15 минут; пересечения показываются на «Сегодня».
- **Оплаты нельзя удалить.** Ни администратор, ни владелец не может стереть
  записанную оплату или возврат, а бронь с оплатами — только отменить (это
  запрещает и сама база). При оплате наличными записывается, сколько дал
  гость, и сдача считается сама. Ошибочную запись владелец аннулирует с
  причиной: она остаётся в карточке зачёркнутой, не входит в суммы и отчёты,
  а в журнале видно, кто и почему это сделал.
- **Уборка.** Задачи появляются сами: после выезда — в день выезда к 12:00
  (если отметить «Выехал» раньше — сразу), у проживающих — раз в N дней
  (настраивается в «Уборке», 0 — только по просьбе). Когда подходит время,
  горничным с включёнными письмами приходит письмо со списком номеров.
  «Убрано» отмечает горничная с телефона или администратор; горничная может
  снять свою отметку в первые 15 минут, администратор — всегда. Чтобы письма
  приходили вовремя, нужен планировщик (`tools/cron.php` каждые 10–15
  минут); без него они уходят, пока открыта админка или кабинет горничной.
- **Баня.** Пока владелец не открыл её (админка → Баня → Настройки →
  «Работает»), на сайте фото, описание и «Сообщить об открытии»; открыть
  без цены за час нельзя. Когда работает — гость выбирает дату, видит только
  свободное время, число часов, гостей и доп. услуги (веники, чай) и сразу
  видит сумму. Цена — за всю баню: час в будни и в выходные, доплата за
  гостей сверх N, скидка проживающим. Баня одна: между сеансами перерыв на
  уборку и протопку (по умолчанию час), две записи на одно время невозможны.
  Заявка держит время, администратор подтверждает её (гостю — письмо),
  накануне приходит напоминание. После каждого сеанса горничной — задача
  «Уборка бани». Оплаты — по тем же правилам, что у номеров: удалить нельзя,
  со сдачей. «Временно закрыта» — запись не принимается, на сайте пояснение.
- **Персональные данные.** Если бронь не состоялась, имя, телефон, почта и
  комментарии стираются автоматически через 30 дней (меняется в «Гости»).
  Сведения о здоровье и паспортные данные сайт не собирает.

## Где что менять

Всё, что нужно заполнить, отмечено `[квадратными скобками]`.
`php tools/check.php` перечисляет каждое такое место с номером строки.

| Что | Где |
|---|---|
| Название, телефон, адрес, мессенджеры, часы работы, реквизиты, условия (оплата, отмена, животные, парковка), что входит в цену | `config/hotel.php` |
| Правила проживания — текст для гостей | `public/rules.php` |
| Ответы на вопросы на главной (кухня, доступность, транспорт) | `public/index.php`, блок «Вопросы» |
| Политика и согласие: даты редакций, хостинг, почтовый сервис | `public/privacy.php`, `public/consent.php` |
| Номера, комнаты, фото, цены, скидки, предоплата, сотрудники | админка `/admin/` |
| Баня: открыть/закрыть (только владелец), описание, правила, фото, цены, часы работы, доп. услуги | админка → Баня → Настройки и сайт |
| Яндекс Метрика, Вебмастер, открыть сайт поисковикам | `config/hotel.php`, в конце файла |

Тексты страниц — обычный HTML внутри PHP-файлов: меняйте только текст между
тегами, не трогая `<?= … ?>`.

## Команды

    php tools/migrate.php                       — создать или обновить базу
    php tools/admin.php list                    — сотрудники
    php tools/admin.php add почта "Имя" owner   — добавить (owner или admin)
    php tools/admin.php password почта          — новый временный пароль
    php tools/cron.php                          — фоновые задачи вручную
    php tools/check.php                         — готовность к запуску
    php tests/run.php                           — тесты (отдельная база hotel_test)

## Перед запуском

- [ ] `php tools/check.php` ничего не находит.
- [ ] Каждое утверждение на сайте — правда. Особенно проверьте: ранний заезд и
      хранение багажа, перенос брони, холодильник в каждом номере, кухня,
      справка о проживании, «скидка на весь срок», вместимость номеров.
      Чего нет — уберите, а не оставляйте «на будущее».
- [ ] В «Номера и фото» — настоящие комнаты и фотографии.
- [ ] Номер в реестре средств размещения указан в конфиге.
- [ ] Подано уведомление в Роскомнадзор об обработке персональных данных
      (pd.rkn.gov.ru) — сайт собирает имена, телефоны и почту.
- [ ] Правила проживания, политика и согласие просмотрены юристом, в них
      проставлены даты редакций, хостинг и почтовый сервис.
- [ ] Тестовая заявка с сайта дошла до администратора, письмо — до гостя.
- [ ] Планировщик запускает `tools/cron.php`, включены HTTPS и резервные
      копии.
- [ ] В `site_url` в конфиге — настоящий домен, а `indexing` — `true`
      (пока `false`, сайт закрыт от поисковиков — удобно на время согласования).
- [ ] Гостиница добавлена в Яндекс Бизнес (карточка на Картах) и 2ГИС, ссылки
      на карточки — в конфиге. Большинство гостей найдут гостиницу именно там,
      по запросам «гостиница Симферополь», «гостиница у КФУ», «гостиница Киевский район».
- [ ] Сайт добавлен в Яндекс Вебмастер, отправлена карта сайта
      (`/sitemap.xml`).

## Как устроен сайт и почему так

Макет взят за основу: палитра, шрифты, арка на первом экране, тёмный блок бани.
Доработано то, что важно именно этим гостям.

**Кто гости.** Командированные, туристы проездом к морю (Симферополь —
транспортный узел Крыма: от вокзала и автостанции «Курортная» — в Ялту и
Алушту, от Центрального автовокзала — в Евпаторию, Феодосию, Керчь), семьи,
абитуриенты и родители студентов КФУ — студгородок рядом, и те, кто живёт
в городе неделями. Многие приезжают ночными поездами и автобусами, планы
часто меняются.

**Где мы.** Киевский район, Марьино, рядом студгородок КФУ на проспекте
Вернадского. До ж/д вокзала, Центрального автовокзала и площади Ленина —
около 4 км, примерно 15 минут на такси. Время в «Что рядом» (config/hotel.php)
прикинуто по карте — проверьте по Яндекс Картам.

| Решение | Почему |
|---|---|
| Крупный шрифт (17–18 px), высокий контраст, большие кнопки | Макет набран мелким светло-серым текстом — с телефона на улице это не прочитать |
| Телефон виден всегда: в шапке, в меню, в нижней панели на телефоне, рядом с формой | Многие гости проще позвонят, чем заполнят форму |
| Календарь свободных дат и расчёт стоимости до заявки | Гость видит, есть ли место и сколько это стоит, ещё до звонка |
| Продлить проживание — в одно сообщение со страницы брони | Командировки продлевают, планы сдвигаются — продление самый частый вопрос |
| Вход в «Мои брони» по коду из письма, без пароля | Пароль от сайта гостиницы никто не запомнит |
| Выбор «позвонить / написать в мессенджер» | На работе или в дороге не всегда удобно говорить по телефону |
| Отдельная страница согласия на обработку данных | С 1 сентября 2025 года согласие должно быть отдельным документом, а не пунктом политики |
| Нет отзывов на сайте — ссылки на Яндекс Карты и 2ГИС | Отзывы на собственном сайте не вызывают доверия; там же гостиницу и ищут |
| Аэропорт не указан в «Что рядом» | Аэропорт Симферополя с 2022 года не принимает рейсы, гости едут поездом, автобусом или на машине |
| Шрифты на своём сервере, Яндекс Карта грузится по кнопке | Быстрее на слабом мобильном интернете и ничего не уходит третьим сторонам без спроса |
| Уведомления по почте, без SMS | Бесплатно и без договора с SMS-шлюзом |

## Яндекс Метрика и Вебмастер

Всё уже встроено — нужно только вписать номера в конец `config/hotel.php`.

**Метрика.**

1. На metrika.yandex.ru → «Добавить счётчик». Адрес сайта — ваш домен.
   Вебвизор включайте, только если будете смотреть записи.
2. Номер счётчика (только цифры) впишите в `analytics.metrika_id`. Если в
   Метрике включили Вебвизор — поставьте и `'webvisor' => true`.
3. Код счётчика из Метрики вставлять никуда не нужно — сайт подключает его сам.
4. В Метрике → «Цели» добавьте цели типа «JavaScript-событие» с такими
   идентификаторами:

   | Идентификатор | Когда срабатывает |
   |---|---|
   | `booking_sent` | гость отправил заявку на бронь — главная цель |
   | `phone_click` | нажал на номер телефона |
   | `messenger_click` | нажал на WhatsApp, Telegram или MAX |
   | `room_open` | открыл окно номера (фото и описание) |
   | `calendar_dates` | выбрал даты в календаре свободных дат |
   | `calendar_to_booking` | из календаря перешёл к заявке |
   | `bath_waitlist` | оставил телефон, чтобы узнать об открытии бани |

Как устроено, чтобы не было проблем с законом о персональных данных:

- Метрика включается только после того, как посетитель нажал «Хорошо» в
  плашке про cookie. «Отказаться» — счётчик не загружается. Передумать можно
  по ссылке «Настройки cookie» в подвале.
- На страницу брони (там секретная ссылка) и в «Мои брони» Метрика не
  подключается. В Вебвизоре содержимое полей форм скрыто.
- В политике обработки данных раздел про Метрику появляется сам, как только
  указан номер счётчика.

**Вебмастер.** webmaster.yandex.ru → добавить сайт → способ подтверждения
«Мета-тег» → из тега `<meta name="yandex-verification" content="…">`
скопируйте значение `content` в `analytics.yandex_verification`. Для Google
Search Console так же — `analytics.google_verification`. Затем в Вебмастере
отправьте карту сайта `/sitemap.xml`.

**Открыть сайт поисковикам** — `'indexing' => true`. Пока `false`, все
страницы помечены «не индексировать», а `robots.txt` запрещает обход: сайт
можно спокойно показывать на согласование.

## Что можно подключить потом

- **Онлайн-оплата предоплаты** (ЮKassa, Т-Касса, CloudPayments). Нужны ИП или
  организация, договор с сервисом и онлайн-касса для чеков (54-ФЗ) — обычно
  касса предоставляется вместе с сервисом. В брони уже есть суммы предоплаты
  и учёт платежей: добавится кнопка «Оплатить» на странице брони и
  автоматическая отметка оплаты. Пока оплату принимаете сами и отмечаете в
  карточке брони.
- **Уведомления администратору в Telegram** — быстрее почты. Серверы Telegram
  за рубежом: без имени и телефона гостя («Новая заявка №7, откройте
  админку») это безопасно; с личными данными — нужно уведомить Роскомнадзор
  о трансграничной передаче.
- **Отзывы** — лучше собирать в Яндекс Картах и 2ГИС: им доверяют больше.
- **Схема проезда от вокзала и остановки** — картинка в блок
  «Как нас найти».
- **SMS** не используются: письма бесплатны, а напоминания и коды входа
  приходят на почту.
